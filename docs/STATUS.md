## 环境级问题（详见 docs/ENV_NUMERIC_BUG.md）

* 宿主 CPython 的 float 运算、`Decimal`/`Fraction`→float、`math.frexp/ldexp` 在部分上下文返回错误值且不报错。
* `1 << -68` 这类负数移位在本环境不抛异常（CPython 规范要求抛 ValueError），说明解释器本身有 UB 级缺陷。
* 结论：**所有数值运算必须走 `numguard`**；新代码审查时检查是否出现裸 `/`、`*`、`-`。
