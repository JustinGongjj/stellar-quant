# UI 质检报告：星图前置页（starmap.html）

**检查时间**：2026-11-14
**检查方法**：无头浏览器截图（1440 / 768 / 390 三视口）+ 计算样式审计 + 键盘 Tab 实测 + 点击交互实测
**页面**：`web/starmap.html`（数据来自 `web/forecast_data.js`）

---

## 结论

**可交付**（修复 8 项后，当前三视口全部通过）。

**最影响观感的 3 条（已修）**：
1. **手机端星图完全崩掉**——标签互相覆盖、内容溢出到卡片外；
2. **键盘完全够不到任何交互**——Tab 只在 BODY 上循环，星簇无法用键盘打开；
3. **页脚对比度 3.54:1**（低于 4.5:1 门槛），且字号档位多达 11 档。

---

## 问题清单

| 级别 | 层 | 位置 | 问题 | 修复 |
|---|---|---|---|---|
| **P0** | L4 | `#sky` 画布 | 固定 `height:620px` 且环形布局不随宽度重排，390px 下星簇与标签严重重叠、文字被裁切 | 窄屏改为**每簇一行**的线性布局，画布高度按簇数自适应 |
| **P0** | L3 | `.clusters`（新增） | 画布无法 Tab，交互元素只有 2 个 canvas，键盘用户无法查看明细 | 新增**可聚焦的簇按钮组**（含 `:focus-visible` 环、`min-height:36px`） |
| **P0** | L3 | `footer` | 文字色 `#5b6883` 对背景对比度 **3.54:1**，低于正文 4.5:1 | 改为 `#8b98b5` → **6.84:1** |
| **P1** | L1 | 全局字号 | 11 档字号（10.5/11/11.5/12/12.5/13/14/16/18/20/26） | 收敛为 **4 档**：11 / 12.5 / 14.5 / 20（+ 标题 26） |
| **P1** | L3 | 详情抽屉 | 用 `div` 冒充关闭按钮，无 `role="dialog"`，Esc 不关闭 | 改 `button` + `aria-label`，加 `role="dialog" aria-modal`，支持 **Esc 关闭**，打开时聚焦关闭按钮 |
| **P1** | L3 | `#sky` | 画布无替代文本 | 加 `role="img" aria-label` |
| **P2** | L3 | 星点脉冲 | 动效不尊重系统偏好 | 加 `prefers-reduced-motion` 判断，减弱脉冲 |
| **P2** | L4 | `#detail` | 固定 `width:420px`，390px 屏会溢出 | 改 `min(420px, 92vw)` |
| **P2** | 数据 | 时效显示 | “数据时效 15 天”实为面板内部跨度，真实滞后是 **60 天** | 改为按 `今天 − 预测时点` 计算并写明日期 |

## 仍需注意（非 UI 问题）

1. **触控目标 36px < 44px 建议值**：簇按钮为了不挤占星图空间做了妥协，若主要为移动端使用建议提到 44px；
2. **数据时效 60 天**：页面上已明确标注，属于数据管道问题而非 UI 问题；
3. **窄屏成员标签省略**：390px 下簇内成员只画星体不写名字，需点击簇查看明细——这是有意的取舍，已在页面提示"点击星簇查看成员明细"。
