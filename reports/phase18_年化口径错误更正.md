# 第十八阶段：一个影响全部历史结论的年化口径错误（2026-11-14）

> 这一轮本来是算 CTA 与股票策略的相关性。过程中发现**前面所有轮次的股票策略年化收益都算错了**。
> 必须先更正，否则后面所有"超额 1.8%"之类的结论都建立在一个错误的分母上。

---

## 一、错误是什么

前面轮次（phase10/11/15/16）为了让"5 日持有、5 日调仓"的策略年化，
用的是这个做法：

```python
ov = pf['net'].rolling(5).mean()      # 5 期移动平均
ann = ov.mean() * 10.08               # × (252/25)
```

**这个做法把收益和波动同时压小了 5 倍**：移动平均后 `ov.mean() ≈ pf['net'].mean()`（均值不变），
但 `ov` 的波动变成原来的 1/5，而年化系数 10.08 是给"每 25 个交易日一个独立观测"准备的。
结果：**算出来的是"把 5 期平滑过的组合"的年化，不是真实组合的年化。**

### 正确的算法

策略每期持有 5 个交易日，T+1 开盘买、T+6 开盘卖；下一期 T+6 开盘买、T+11 开盘卖。
**相邻两期首尾相接，没有重叠**——所以直接链式复利即可：

```python
nav = np.cumprod(1 + period_returns)
ann = nav[-1] ** (252 / (len(period_returns) * 5)) - 1
```

## 二、更正后的数字（统一口径：`stellarq.metrics.annualise_periodic`）

| 口径 | 策略 | 等权基准 | 超额 |
|---|---|---|---|
| 期均收益 | +0.731% | +0.467% | +0.264% |
| 期波动（5 日） | 5.28% | 4.83% | 1.57% |
| **算术年化** | **36.83%** | 23.54% | **13.29%** |
| **几何年化（链式复利）** | **35.40%** | 19.79% | **13.51%** |
| 年化波动 | 37.46% | 34.31% | **11.15%** |
| **Sharpe（策略/基准）** | **0.98** | 0.69 | — |
| **超额 Sharpe = IR** | — | — | **1.19** |
| 最大回撤 | −31.69% | −25.75% | −11.56% |
| 累计净值（2.1 年） | 1.880 | 1.457 | 1.302 |
| 期胜率 | 60.0% | 61.9% | 54.3% |

**之前报的 7.26% / 超额 2.56% / IR 1.18 是"5 期平滑后"的数，不是策略本身的数。**

### 为什么两种口径差 5 倍

5 期移动平均把波动压到 1/5（5.28% → 1.06%），均值不变，
于是年化系数 10.08 一乘，得到"波动 7%、收益 7%"的假象。

**两种口径都不能单独当结论**：
- 链式复利（35.4%）把 2.1 年的一次实现当外推；
- 平滑口径（7.3%）人为抹掉了风险。

**正确写法是同时报告期均、期波动、期数**，让读者看到这组数字的置信水平：
期均 +0.731%、期波动 5.28%、105 期（2.1 年）。

## 三、这对之前结论的影响

| 之前的结论 | 是否还成立 | 说明 |
|---|---|---|
| "超额 2.5%，IR 1.18" | **数值错，但结论方向对** | 真实超额 13.3%/年（算术）、**IR 1.19**（比原来还略高） |
| "IR 1.37，最优配置" | **不成立** | 真实 IR 约 1.19 |
| "容量 1–2 亿，超额归零" | **方向正确，数值需重算** | 冲击成本的绝对量级（22.6bp @1亿）没变，但分母现在是 26.4bp/期 的超额 |
| "幸存者偏差使超额降 1.22pp" | **成立**（这是独立修正） | 但相对 13.3% 的算术超额，占比从 60% 降到 9% |
| "CTA 与股票相关性 0.161" | **成立** | 相关性不受年化口径影响 |
| CTA 年化 6.22% | **成立** | CTA 用的是日频链式复利，口径本来就对 |

**最重要的一条**：幸存者偏差的相对影响从"吃掉 60% 的超额"降到"吃掉 9%"——
因为之前的分母太小了。

## 四、CTA × 股票组合（相关性部分是可信的）

| 组合 | 年化净收益 | 波动 | Sharpe | 最大回撤 |
|---|---|---|---|---|
| 纯股票策略 | 35.40% | 37.46% | 0.95 | −31.4% |
| 纯 CTA 趋势 | 6.31% | 4.60% | 1.37 | −10.7% |
| 股票 50 / CTA 50 | 22.69% | 20.18% | 1.12 | −16.3% |
| 股票 40 / CTA 60 | 19.53% | 17.07% | 1.14 | −12.9% |
| **股票 30 / CTA 70** | 16.30% | 14.26% | **1.14** | **−9.4%** |

**相关性 0.161（低）**，组合确实改善了风险收益比：
- 纯股票 Sharpe 0.95、回撤 −31.4%；
- 30/70 组合 Sharpe 1.14、回撤 −9.4%。

**这是本轮唯一站得住的正面结论**：CTA 与股票策略低相关，组合后回撤从 −31% 降到 −9%，
代价是收益从 35% 降到 16%。

## 五、必须承认的事

1. 这个错误从 phase10 一直带到 phase17，**四轮报告的绝对收益数字都是错的**；
2. 相关性、冲击成本的绝对量级（bp）、因子 IC、CTA 这些**不受影响**的结论仍然成立；
3. 但凡是"年化收益/超额/IR/容量"的判断，都要按本文重算；
4. **股票策略 35.4% 的年化在 2.1 年样本上不可外推**——这个数字本身波动极大（年化波动 37%），
   统计意义非常弱，不能拿去做预期。
