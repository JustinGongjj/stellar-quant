# 宏观与周期数据获取报告

> 取数时间：2026-11-15
> 数据源：Wind 万得 EDB（积分阻断前已取部分）＋ FRED（圣路易斯联储）＋ 世界银行 WDI，三路公开/授权渠道

## 一、结论先行

Wind 账户积分在首个大数据包拉取后耗尽，无法继续提数。已改用 **FRED** 与 **世界银行 WDI** 两路免费公开渠道补取长序列。三路合计落地：

- **Wind（2011 年至今子集）**：10 个核心指标、1000 个数据点（月/季/年频）
- **FRED（年度长序列）**：3 个指标、107 个数据点（GDP 现价 1992–2025、GDP 实际增速 1992–2025、CPI 通胀率 1987–2025）
- **世界银行 WDI（年度长序列）**：6 个指标、150 个数据点（2000–2024，美元/比率口径）

**合计 19 个指标、1257 个数据点**，覆盖 GDP、CPI、PPI、产能利用率、库存、利润、居民消费、人均收入等核心周期维度。

**仍无法获取的，均为结构性缺口（非积分、非权限）**，公开渠道不覆盖，已如实标注。

## 三、仍存在的缺口（结构性，公开渠道不覆盖）

### 3.1 2000–2010 早段月度/季度序列
- **缺口**：GDP/CPI/PPI/产能利用率等的 2000–2010 月度/季度长序列。
- **现状**：FRED/WDI 仅提供年度；Wind 有早段数据但积分阻断。
- **性质**：Wind 侧为积分阻断（充值可补）；公开渠道侧为**结构性缺口**（FRED/WDI 不提供中国月度/季度早段序列）。
- **恢复路径**：Wind 充值后按指标代码以 `beginDate=20000101, endDate=20101231` 补取。

### 3.2 利润率
- **缺口**：工业企业利润率（利润总额 / 营业收入）。
- **现状**：利润总额已取（M0000556），但营业收入指标（M5767811）未取回，暂无法计算。
- **性质**：Wind 积分阻断。且 2017 年前为「主营业务收入」口径，拼接时需注意口径断裂。

### 3.3 第二类 · 分行业产能周期
- **缺口**：分行业工业产能利用率（采矿业/制造业/电力等）、分行业资本开支、在建工程、ROE、毛利率。
- **现状**：本次未取。
- **性质**：Wind 积分阻断；分行业产能利用率统计局自 2013 年起按季发布，更早年份为结构性缺口。分行业 ROE/资本开支需走上市公司财报聚合，公开渠道不直接提供长序列。

### 3.4 第三类 · 居民部门
- **缺口**：居民收入占 GNI 比重、消费倾向、储蓄率、分收入组数据。
- **现状**：WDI 提供人均 GNI、人均 GDP、居民消费支出（可间接推算部分比率），但**储蓄率、消费倾向、分收入组**本次未取到。
- **性质**：储蓄率/消费倾向需资金流量表或住户调查，公开 API 不覆盖；**分收入组（五等分/城乡）微观调查（CFPS/CHFS）不在 Wind、不在公开 API**，需自行申请微观数据，属结构性缺口。

### 3.5 第四类 · 地方财政
- **缺口**：地方一般公共预算、政府性基金、隐性债务、专项债投向全口径。
- **现状**：本次未取。
- **性质**：Wind 积分阻断。**隐性债务无官方公开全口径数据**，需用城投年报（有息债务）或机构估算替代，属「待核验」口径，结构性缺失。

## 六、待核事项

1. **口径差异**：FRED/WDI 为美元/比率口径，与统计局人民币口径存在汇率换算与统计口径差异，实证前需对齐口径或统一换算基准。
2. **转录复核**：Wind 2011–2026 数据为工具返回内容转录，已做长度校验与关键时点抽样核对（2025 GDP 现价 140.2 万亿、PPI 2021-10 峰值 13.5%、产能利用率 2020Q1 疫情季 67.3%），实证前建议与 Wind 终端/国家统计局复核关键时点值。
3. **结构性缺口**：隐性债务、CFPS/CHFS 分收入组、2000–2010 月度早段，公开渠道不覆盖，需替代口径或外部数据源，无法通过当前渠道补全。
4. **本数据仅用于实证校准与周期相位识别，不构成投资建议。**
