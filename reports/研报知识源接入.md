## 二、接入方式

```
insight-hub/vault/<分类>/*.md
   │  带 YAML frontmatter（title/tags/source/date）
   ▼
InsightHub.research_docs()          # stellarq.bridge.insight
   ▼
scripts/index_research.py            # 关键词打分 → 按域/主题聚合
   ▼
reports/data/research_index.json
   ▼
scripts/attach_research.py           # 挂到星图每域的 research_base + 每节点 research
   ▼
星图侧栏「研报底座」区块
```

## 四、更新方式

投研工作站新增研报后，重跑三步：

```bash
PYTHONPATH=src python3 scripts/index_research.py     # 重建索引
PYTHONPATH=src python3 scripts/attach_research.py    # 挂到各域
PYTHONPATH=src python3 scripts/build_atlas_html.py   # 生成页面
```

## 五、已知限制

1. **只看标题+前 6000 字打分**，长研报后半部分未参与主题判定；
2. 命中是**关键词计数**，不是语义检索——可能出现主题漂移（如"智能体"命中"人工智能"）；
3. 每域最多展示 6 份代表文档，完整清单在 `research_index.json`；
4. 研报正文**未做实体抽取**，还不能直接回答"这份研报提到哪些公司"。
