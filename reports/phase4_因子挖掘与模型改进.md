**三点解读**（不是结论，是待验证的观察）：
1. **量能类因子（VSTD / AMT_RATIO / VSUMD）系统性最强**，比价格类因子稳定；
2. 方向高度一致：**放量、量能不稳 → 后续跑输**，这是典型的 A 股短期反转与拥挤度特征；
3. `MAX`（突破新高）几乎无 IC（+0.008～0.017），`CNTD`（涨跌天数差）也弱（−0.06～−0.12）——
   说明「突破」和「连涨」在这段样本里不是有效信号，不要被叙事带跑。

完整 57 行见 `reports/data/factor_mine_h5_partial.csv`（AMIHUD 因计算量过大仍在跑，未纳入）。

## 三、模型：DoubleEnsemble + 概率校准

**配置**：18 个通过筛选的因子（|ICIR|>0.4 为主）、两轮 GBDT 集成、日期级样本重加权、
Platt 校准（只在验证集拟合）、训练/验证/测试 70/15/15、每 5 个交易日一个非重叠截面。

| 指标 | 结果 |
|---|---|
| 样本外平均 RankIC | **0.0735**（106 个截面，2024-07-18 → 2026-09-15） |
| Brier（校准后 / 原始） | 0.24996 / 0.24996 |
| ECE（期望校准误差） | 0.0128 |
| 训练集 IC（第一轮 / 第二轮） | 0.050 → 0.059 |

> Brier 接近 0.25 说明「跑赢中位数」这个二分类目标本身近乎硬币，校准只是把它摆正，
> 不产生额外信息——**排序能力体现在 RankIC 上，不在概率上**。这一点必须写进前端口径。

## 五、这一轮真正改进了什么

1. **数据**：从「99% 的因子都显著」的错误前提，换成 81.5% 合规样本的干净面板；
2. **因子**：从 37 个拍卖式检验，改成 57 个候选 + 全流程显著性校正，并且方向可解释；
3. **模型**：RankIC 0.0445 → **0.0735**（同口径、同区间长度），主要来自特征质量而非模型结构；
4. **回测**：重叠修正口径固定成代码（`portfolio.construct`），杜绝「把 5 日收益乘 50 倍」的经典错误。
