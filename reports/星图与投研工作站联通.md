# 星图 ⇄ 投研工作站：双向联通说明

## 一、连接方式

```
投研工作站 (Insight Hub, :8923)          未来星图 (stellar-starmap, :8791)
  insight-hub/data/insight.db  ──只读──►  stellarq.bridge.insight.InsightHub
       kb / industry_maps /                    │
       chainmaps / entities                    ├─► scripts/attach_insight.py
                                               │     挂到每个星图域的 knowledge_base
                                               └─► 页面侧栏「知识底座」区块

  产业链图谱页 ──「送入未来星图 ↗」──────►  /?track=<赛道名>  自动切换并加载
  顶部「投研工作站 ↗」按钮 ◄──────────────  跳回 :8923
```

## 二、星图从投研工作站获取什么

| 表 | 行数 | 用途 |
|---|---|---|
| `industry_maps` | 5 个赛道 | 上游/中游/下游分层、卡脖子等级、技术瓶颈、玩家名单 |
| `chainmaps` | 5 张 | 产业链思维导图（低空经济、机器人、半导体、具身智能、水下机器人） |
| `kb` | 22 条 | 知识库条目（投后预警、产业链研究等） |
| `entities` | 2,806 个 | 实体库 |
| `frontier_news` | 36 条 | 前沿情报 |

**已挂载的域**：具身智能（图谱+导图）、AI 未来（人工智能 v28）、商业航天（v1）、低空经济（导图）
**未挂载**：量化因子、瓯海区、全球格局、美股（投研工作站暂无对应赛道）

## 三、约束

1. **只读**：`sqlite3` 以 `mode=ro` 打开，绝不写投研工作站的数据；
2. **可降级**：数据库不存在时返回空结果，星图独立可运行；
3. **不改投研工作站数据**：只在 `app.js` 产业链图谱页加了一个跳转按钮。

## 四、接口

```bash
# 投研工作站数据概况（只读）
curl http://127.0.0.1:8791/api/insight/stats
# {"available": true, "kb": 22, "industry_maps": 5, "entities": 2806, ...}

# 直达某赛道
http://127.0.0.1:8791/?track=商业航天

# 重新挂载（投研工作站更新图谱后跑一次）
PYTHONPATH=src python3 scripts/attach_insight.py
```

## 五、已知限制

- 投研工作站 v2.64（:8924）的 API 需要登录态，星图直接读 SQLite 绕过登录，**因此只读**；
- 知识库只有 22 条（多为投后预警），产业研究内容主要在图谱里；
- 挂载是**快照式**的，投研工作站更新后需重跑 `attach_insight.py`（未做自动同步）。
