# 星衡量化 · Stellar Quant

> 在确定与不确定之间，寻找平衡与发展。**和而不同。**

一套面向 A 股的量化研究框架 + 产业分析框架 + 可视化工作站。

**这个仓库最大的特点是：它记录了大量失败。**

---

## 一句话结论

> 做出了一条能用但**容量很小**的量化策略（IR 1.1–1.3，容量 1–2 亿）；
> 验证了一条不相关但**样本很长**的 CTA 策略（Sharpe 0.57，21 年）；
> 建了一套产业分析框架，但它**不能产生 alpha**，只能辅助认知；
> 期间**推翻了 6 个自己提出的假设**，改正了 1 个影响全部历史数字的计算错误。

## 核心结果

### 股票量化策略（v4）

| 指标 | 数值 | 条件 |
|---|---|---|
| 模型 | DoubleEnsemble + Platt 校准，19 个量价特征 | — |
| 样本外 RankIC | **0.0758** | 105 期（2024-07 → 2026-09） |
| 校准误差 ECE | **0.0037** | 同上 |
| 年化超额 | **+3.06%** | 1 亿规模，含冲击成本 |
| **含幸存者修正** | **+1.84%** | 唯一对外口径 |
| IR | **1.1–1.3** | 成本假设敏感 |
| **容量上限** | **1–2 亿** | 超过后超额归零 |

### CTA 趋势策略（可信度最高）

| 策略 | 年化 | Sharpe | 最大回撤 |
|---|---|---|---|
| **趋势 10/30 日** | **6.22%** | **0.57** | −18.0% |
| 等权买入持有 | 5.23% | 0.37 | −48.6% |
| **随机信号（对照）** | **−6.38%** | −0.88 | −77.0% |

21 年样本，带随机对照 —— 这是全项目最可信的结论。

### 库存周期 × 行业（唯一通过三道闸门的信号）

| 行业 | 超额（3/6/9 月窗口） | t 值 |
|---|---|---|
| **计算机设备**（被动去库） | **+3.40% / +3.81% / +1.85%** | **3.03 / 2.72** / 1.31 |
| 通信设备（被动补库） | +5.09% / +2.67% / +0.87% | 2.94 / 1.79 / 0.61 |

三道闸门：换判定窗口、前后半段切分、逐年检验，全部通过。

## 六个被证伪的假设

**这一节比正面结论更重要。**

| # | 我们曾相信 | 实测结果 |
|---|---|---|
| 1 | 美林时钟能择时 | 超额 +2.53% → **−1.94%**，IR 1.18 → −0.58 |
| 2 | 时钟做过滤器有效 | 换参数即失效，改善集中在单一年份 → **过拟合** |
| 3 | 对冲能降低回撤 | 对冲后 3.3% vs 不 hedge 7.72%，回撤几乎不变 |
| 4 | 打板/抓龙头可行 | 涨停 70,003 次，**可成交率仅 26%**，期望 +0.13% 低于成本 |
| 5 | 拉长持有期能提容量 | 换手 **0.69 → 0.95 反而上升** |
| 6 | 产业分析叠加量化能提升 | 重叠率 **0.5%**（34/6300），IR 1.91 → 1.88 |

**另加两条**：
- 缠论结构当横截面因子 → 消除前视后 IC ≈ 0（第一次测出 0.2556 是**前视偏差幻觉**）
- 美林时钟「中国化」改良 → 货币×信用框架 40.1%，**比传统的 52.0% 更差**

## 快速开始

```bash
git clone https://github.com/JustinGongjj/stellar-quant.git
cd stellar-quant
pip install -e .
```

### 需要先准备行情缓存

行情缓存体积大，不进仓库。设置环境变量指向你的缓存目录：

```bash
export STELLARQ_CACHE=/path/to/your/parquet/cache
```

目录结构要求（wide 格式，列=股票，行=日期）：
```
$STELLARQ_CACHE/wide2/
  wide_close.npy  wide_open.npy  wide_high.npy  wide_low.npy
  wide_amount.npy wide_turnover.npy wide_float_mktcap.npy
  wide_valid.npy  wide_dates.npy  wide_syms.npy
```

**没有缓存也能看报告**：`reports/` 与 `reports/data/` 是全的。

### 跑起来

```bash
python3 -m stellarq.metrics                # 口径自检（年化、IR、回撤）
python3 scripts/rebuild_all.sh            # 重建星图页面 + 打包
python3 -m http.server 8000 -d web        # 本地预览
```

## 数据来源与限制

### 已接入

| 来源 | 指标 | 区间 |
|---|---|---|
| Wind EDB（统计局口径） | 10 个（GDP/CPI/PPI/产能利用率/存货/利润） | 2011-01 ~ 2026-10 |
| FRED | 3 个 | 1992–2025 |
| 世界银行 WDI | 6 个 | 2000–2024 |
| 腾讯行情 | A 股日线（5,225 只） | 2012–2026 |

### 三条硬约束（重要）

1. **幸存者偏差**：深沪 2012 年以来退市 **123 只**，面板覆盖 **0 只**
   → 所有超额需打折 **0.73–1.71pp**
2. **冲击成本系数 k = 0.0137** 是按文献量级估的，**未经过实盘校准**
   → 容量 1–2 亿这个结论完全依赖它
3. **研报知识库质量**：203 份中只有 **144 份（71%）**可用，其余截断或解析失败

### 结构性缺口（公开渠道不覆盖）

隐性债务全口径、CFPS/CHFS 分收入组、2000–2010 月度/季度序列、分行业产能利用率。

## 可信度分级

| 结论 | 等级 | 理由 |
|---|---|---|
| CTA 趋势有效 | **A** | 21 年样本、有随机对照 |
| 量价因子有效 | **A** | 3,000+ 截面、BH 校正 |
| 库存周期×行业 | **B+** | 过三道闸门，但仅 62 个月 |

| 宏观当特征有效 | **B** | 方向一致但仅 105 期 |
| 美林时钟择时 | **D** | 已否定 |
| 面板无幸存者偏差 | **F** | 已证伪 |
| 产业框架产生 alpha | **F** | 三条路径全部证伪 |
