# 星图 · 未来预测框架（认知层）

> 这份文档回答一个问题：**我们到底能预测什么、不能预测什么、凭什么这么说。**
> 所有数值来自 `reports/data/forecast.json`，每个结论都标了证据等级和失效条件。

---

## 一、先纠正一个认知：原星图不是预测

你最初给的"未来星图"，它的因子载荷 `li`/`le` 和四情景概率**都是人工设定值**，
没有可复现的估计口径。它是一张"好看的结构图"，不是预测模型。

本仓重做后的原则是：**每个节点、每条边、每个概率，都必须能追到一个跑出来的数字。**

---

## 二、四层预测框架

```
┌─ L1 状态层 ── 我们在经济周期的哪里？
│    美林时钟四相位（真实宏观数据，按公布日对齐）
│
├─ L2 因子层 ── 哪些因子现在有效？
│    57 个因子的 ICIR + 8 个星簇（相关性聚类）
│
├─ L3 预测层 ── 模型给谁高分？
│    v4 打分 + RankIC + 校准误差 + 时效性声明
│
└─ L4 证据层 ── 这些结论有多可信？
     每条的等级（A/B/C/D/F）+ 失效条件
```

## 三、L1 状态层：当前在「衰退」

| 项目 | 数值 |
|---|---|
| 相位 | **衰退** |
| 时点 | 2026-11-01 |
| CPI 同比 | 0.7% |
| GDP 累计同比 | 4.6% |
| 制造业 PMI | 49.3 |
| 历史相位分布 | 滞胀 45 月、衰退 38、复苏 21、过热 14、无法判定 61 |

**必须知道的三件事**：
1. 这个"衰退"是**方向判定**（增长↓ 通胀↓），不是严格的经济学衰退定义；
2. 中国市场的特殊性：**衰退期股票历史上表现不差**（往往是政策宽松期），
   所以"衰退"这个词在这里不能当卖出信号用；
3. 时钟做**择时**已被实测否定（phase11、phase13），它只适合做**状态描述**。

## 四、L2 因子层：8 个星簇

按相关性（|corr|≥0.45 平均连接）聚出来的真实结构：

| 星簇 | 因子 | 簇均 ICIR | 读法 |
|---|---|---|---|
| **动量与位置** | MA10/MA20/MA60/MIN5/MIN20/RET20 | **+0.405** | 最强正向簇；中期动量 |
| 量能异动 | AMT_RATIO60/20、VSUMD60、VMA60 | −0.248 | 放量后偏弱（反转） |
| **量能波动·VSTD20** | VSTD20、VSTD10 | **−0.635** | **最强负向簇**；量能越不稳越差 |
| 规模与活跃度 | AMT_MA5、LN_CAP | −0.312 | 小盘+高活跃短期占优 |
| 波动与换手 | STD20、TURN5 | −0.318 | 高波动高换手后续偏弱 |
| 形态与离散度·KMID | KMID、CLOSE_POS | −0.176 | 日内形态，弱 |
| 量能波动·VSTD60 | VSTD60 | −0.527 | 长窗口量能波动 |
| 形态与离散度·CORR20 | CORR20 | −0.428 | 量价同步度高 → 偏弱 |

**这张表的用途**：星图上的每个"星座"就是一行；节点亮度 = |ICIR|；连线 = 相关性。
**读法上最重要的一条**：动量簇是唯一的正向主线，其余全部是"避免型"因子（负 ICIR）。
这意味着**策略本质上是在做"排除"，而不是在"挑选"**。

## 五、L3 预测层：模型能给出的东西，比想象中少

| 项目 | 数值 |
|---|---|
| 模型 | v4（DoubleEnsemble，19 个量价特征） |
| 样本外 RankIC | **0.076** |
| 校准误差 ECE | 0.0037 |
| 样本外期数 | 105（约 2.1 年） |
| 打分时点 | 2026-09-15 |
| **时效滞后** | **45 天**（面板截断在 2026-09-30） |

**RankIC 0.076 是什么概念**：模型对"未来 5 日收益排序"的解释力约 0.6%。
相当于在 100 只股票里，它能帮你把最好的 20 只从第 50 名提到第 40 名左右。
**这不足以支持"预测个股涨跌"，只够支持"轻微倾斜仓位"。**

**时效问题必须说清**：当前预测基于 2026-09-15 之前的分数，**不是今天的预测**。
要出"当日预测"，需要先补齐数据到最新交易日并重跑打分（数据源目前受限）。

## 六、L4 证据层：五条结论的证据等级

| 结论 | 等级 | 依据 | 何时失效 |
|---|---|---|---|
| 量价因子簇全样本显著 | **A** | 多数 q<0.01，3,000+ 截面 | 小盘效应消失 |
| 宏观变量当特征可提升 IC | **B** | IC 0.0434→0.0501，仅 105 期 | 换窗口后不成立（未充分检验） |
| CTA 与股票低相关 | **B** | corr 0.161，2.1 年重叠 | 危机时相关性会趋近 1（未检验） |
| **美林时钟做择时有效** | **D（已否定）** | 超额 +2.53%→−1.94% | — |
| **面板无幸存者偏差** | **F（已证伪）** | 缺 123 只退市股（2.45%） | — |

**等级定义**：A=多轮独立检验通过；B=方向一致但样本不足；C=仅有单次结果；
D=已被否定；F=已被证伪。

## 七、这个框架能回答什么问题

| 问题 | 能否回答 | 依据 |
|---|---|---|
| 现在经济在哪个阶段？ | ✅ | L1，真实宏观数据 |
| 哪些因子现在有效？ | ✅ | L2，ICIR + 显著性 |
| 因子之间什么关系？ | ✅ | L2，相关性聚类 |
| 明天哪些股票会涨？ | ❌ | RankIC 0.076，做不到 |
| 未来 5 日哪些股票相对强？ | ⚠️ 弱信号 | 只能做轻微倾斜 |
| 策略能赚多少？ | ⚠️ 区间很宽 | 见 phase18 口径更正 |
| 什么时候该空仓？ | ❌ | 时钟择时已否定 |

## 八、下一步（把框架变成可用的东西）

1. **补齐数据到最新交易日** → 让 L3 变成真·当日预测（当前卡在数据源）；
2. **前端星图**：8 个星簇 = 8 个星团，亮度=ICIR，连线=|corr|，点击展开成员与证据；
3. **加一个"因子有效期"监测**：每月重算 ICIR，画出趋势，识别失效中的因子；
4. **CTA 星团**：把 18 个期货品种也放进星图，标注与股票簇的相关性。

> 一句话：**这个框架的价值不在"预测得多准"，而在"知道自己有多不准"。**
