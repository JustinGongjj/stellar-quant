# 缠论工作站接入：一次前视偏差的自我修正

## 一、结论先行

**第一次测出 IC 0.2556（是 v4 模型 0.0758 的 3.4 倍）——这是假的。
排查后发现是前视偏差。修正后 IC 全部趋近于 0（−0.042 ~ +0.006）。**

**缠论结构特征对我们的量价模型没有增量价值。**

## 二、我犯的错误

### 第一次测的结果（错）

| 特征 | IC |
|---|---|
| ch_pos_pct | **+0.2556** |
| ch_trend | +0.2009 |
| ch_pos | +0.1869 |
| 综合缠论分 | **+0.2253** |

当时我写了一句：「IC 0.2+ 在量价因子里不可能，必须排查是不是未来函数」。

### 前视偏差怎么产生的

| 项 | 日期 |
|---|---|
| 我的面板数据最后一期 | **2026-09-30** |
| 取用的截面 | **2026-09-18** |
| 缠论工作站 `/api/chan` 返回 | **2026-11-15（今天，实时）** |

**等于用未来 6 周的结构，去预测 9 月 18 日之后 5 天的收益。**
IC 0.25 不是预测力，是把答案抄了一遍。

## 三、怎么修的

缠论工作站的 `server/lib/chan.js` 里，`analyze(rawBars, opts)` 是**纯函数**——
传入什么 K 线就计算什么结构。

所以正确做法是：**按截面日截断 K 线，在本地调用 `analyze()` 重算**，
而不是调那个只返回"当前"快照的 API。

## 四、修正后的结果

4 个历史截面（2025-09 / 2025-12 / 2026-03 / 2026-06）：

| 特征 | IC 均值 | 各截面 |
|---|---|---|
| ch_trend | **−0.0061** | −0.123 / −0.034 / +0.167 / −0.034 |
| ch_pos | **−0.0356** | −0.017 / −0.195 / −0.013 / +0.082 |
| ch_pivots | −0.0129 | −0.017 / +0.041 / −0.040 / −0.036 |
| ch_pos_pct | **−0.0417** | −0.041 / −0.211 / −0.002 / +0.086 |
| ch_last_signal | −0.0012 | −0.061 / −0.010 / +0.079 / −0.013 |
| ch_sig_age | +0.0061 | −0.043 / +0.015 / +0.023 / +0.030 |

**全部在 ±0.05 以内，且各截面符号来回翻转**——没有稳定的方向，就是噪声。

## 五、缠论特征真的没用吗——更细的判断

**不能这么说。严格的结论是：**

> 「把缠论结构（趋势类型、中枢位置、买卖点）当**横截面因子**使用，没有效果。」

**但有三点没被这次检验否掉：**

1. **样本只有 4 个截面**——不足以否定一个特征
2. **买点/卖点可能是择时信号而非截面信号**：它告诉你"这只股票现在能不能买"，
   而不是"这批股票里哪只更好"。我测的是后者
3. **缠论的多级别联立（区间套）没有测**——我只用了单一日线级别

产出 `reports/data/chanlun_feats.parquet`。

### 3. 修了一个信号解析 bug

站点信号编码是 `1B/2B/3B`（买点）、`1S/2S/3S`（卖点）。
我第一版用 `'买' in kind` 判断，但 `kind` 是 `3B` 不含中文，**结果 4790 只全部被判成卖点**。

修正后分布正常：买点 1919 / 卖点 2312 / 无信号 559。

## 七、接进五碗面的技术与结论

**技术面这一栏，缠论填不上。**

| 面 | 状态 |
|---|---|
| 情绪面 | ✅ IC +0.0919（最强） |
| 资金面 | ✅ IC +0.0329 |
| 基本面 | ⚠️ 只有 BP，IC +0.0276 |
| **技术面** | ❌ **缠论截面特征 IC≈0，不能用** |
| 政策面 | ❌ 完全缺失 |

## 八、下一步该做什么

技术面要补，路子有三条：

1. **测缠论的择时用法**（而非截面用法）——需要单票时间序列上的买卖点后验，样本会很小
2. **用传统技术指标**（MA、RSI、布林）做截面——这些我们其实已有（MA10/20/60 在动量簇里）
3. **放弃技术面独立成栏**，把它的信息合并进情绪面

**我倾向 3**——因为动量/均线位置这些"技术面"要素，本来就在我们 ICIR +0.440 的动量簇里了。
缠论提供的是中枢、笔、线段这套结构语言，它在**解释和沟通**上有价值，
但在**这个横截面选股任务**上没有。

## 九、局限

1. 只有 4 个截面，统计力弱
2. 只测了日线单级别
3. 只测了截面 IC，没测择时
4. 未做样本外切分

---

**这次最重要的收获不是缠论有没有用，而是：一个看起来 3 倍于基准的 IC，第一反应应该是「哪里错了」，而不是「发现了 alpha」。**
